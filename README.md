
  # BARO-MobileUI

  This is a code bundle for BARO-MobileUI. The original project is available at https://www.figma.com/design/Q49GNx8cbuwPZkYKa5LVvJ/BARO-MobileUI.

  ## Running the code

  Run `pnpm i` to install the dependencies.

  Run `pnpm run dev` to start the development server.

  ## Vercel Preview Deployment

  This project is configured for Vercel preview deployments on pull requests.

  ### Setup

  1. Connect your GitHub repository to Vercel.
  2. Add the following secrets to your GitHub repository:
     - `VERCEL_TOKEN`: Your Vercel token (get from https://vercel.com/account/tokens)
     - `VERCEL_ORG_ID`: Your Vercel organization ID
     - `VERCEL_PROJECT_ID`: Your Vercel project ID
  3. Pull requests will automatically deploy previews to Vercel.
